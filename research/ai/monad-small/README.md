# Monad 真实行情小模型

本实验使用 GeckoTerminal 索引的 Monad 主网 DEX 行情。
它重新训练一个小模型，不沿用股票 PPO 模型的权重。
训练在本地执行。模型参数与推理部署在 Monad 测试网。

网页：[交易 AI](https://lp.chayu123.me/#ai)。
模型：[0x5dd31af6d70b7633fd5da3e30c03feb5fde00618](https://testnet.monadscan.com/address/0x5dd31af6d70b7633fd5da3e30c03feb5fde00618)。

## 数据

| 资产 | 代币地址 | 真实小时 K 线 | 数据时间 UTC |
| --- | --- | ---: | --- |
| CHOG | `0x350035555e10d9afaf1566aaebfced5ba6c27777` | 1,996 | 2026-07-22 至 2026-10-17 |
| WMON | `0x3bd359c1119da7da1d913d1c4d2b7c461115433a` | 1,997 | 2026-07-25 至 2026-10-17 |
| WETH | `0xee8c0e9f1bffb4eb878d8f15f368a02a35481242` | 1,999 | 2026-07-25 至 2026-10-17 |

`raw/` 保存九份提供商原始响应。
`dataset.json` 保存清洗后的数据、池地址、URL 和响应哈希。
池按采集时的流动性选择，不按回测收益选择。
代币以地址匹配，不只用名称匹配。

价格与成交量的单位都是 USD。
这些数据是链上交易的第三方索引，不是自行重放的 Swap 日志。
没有使用合成训练数据，也没有前向填充缺失 K 线。
CHOG 有 75 处缺口，WMON 有两处，WETH 有一处。
两个 CHOG 时间点和一个 WMON 时间点存在冲突，已剔除。
特征与标签窗口跨越缺口时，整条样本不用。

## 输入和标签

输入共 12 个特征，只使用决策时已经完成的 K 线：

1. 1、3、6、12、24 小时对数收益，共五个特征。
2. 当前 K 线的振幅与收盘价之比。
3. 当前 K 线的收盘价相对开盘价的变化。
4. 收盘价相对 6、24 小时均价的偏离，共两个特征。
5. 6、24 小时收益波动率，共两个特征。
6. 当前成交量相对过去 24 小时平均量的对数差。

标准化均值和尺度只用训练集计算。
标准化结果裁剪到 [-4,4]，然后编码成 Q12 整数。
模型不读取钱包余额或 DeFi 持仓。

监督标签是下一根 K 线开盘后四小时的价格方向。
上涨超过 1% 为 BUY，下跌超过 1% 为 SELL，其余为 HOLD。
输出是三个整数分类分数，最大分数决定动作。
同分时按 HOLD、BUY、SELL 的顺序取第一个。
分数不是预期收益，也不是校准概率。

## 训练和结果

按统一时间边界分训练、验证、测试，不随机打乱划分。
训练标签不跨入验证区间，验证标签不跨入测试区间。
历史特征可以读取边界以前已知的行情。

| 分区 | 样本数 | CHOG / WMON / WETH |
| --- | ---: | --- |
| 训练 | 2,853 | 610 / 1,106 / 1,137 |
| 验证 | 935 | 143 / 396 / 396 |
| 测试 | 853 | 53 / 400 / 400 |

比较 39 参数线性分类器与 131 参数小网络。
按验证集的加权交叉熵选择模型和轮次。
最终选择 `12 → 8 ReLU → 3`，第 141 轮。
这是监督分类，不是强化学习。

训练前向包含整数权重、偏置与除法的量化规则。
权重为 int16/Q14，输入与激活为 Q12。
偏置为 int32，尺度为 2^26。
每层把偏置和点积相加，再除以 2^14，向零截断。
JavaScript 用 BigInt，Solidity 用 int256 累加。

测试准确率为 55.45%，平衡准确率为 44.81%。
始终预测 HOLD 的测试准确率为 55.10%。
当前结果不足以证明模型具有交易优势。

| 测试资产 | 模拟收益 | 模拟买卖条数 |
| --- | ---: | ---: |
| CHOG | -26.27% | 6 |
| WMON | -30.01% | 16 |
| WETH | 0.00% | 0 |

这些是样本外的历史模拟，不是真实钱包成交。
BUY 切换为持币，SELL 切换为现金，HOLD 保持仓位。
每个决策观察四小时，观察窗口不重叠。
缺口前按最后可观察价格结算，测试结束也结算。
持有基准也只比较同样的可观察窗口，不表示连续持有收益。
缺口结算是回测约定，真实交易未必能按该价格成交。

成本包含池名标注的手续费与每边 20 bps 假设滑点。
没有计入 gas、资金容量和多跳换汇的额外成本。
CHOG/WMON 的 USD 估值不表示可以直接用美元成交。
不同资产高度相关，池筛选使用当前流动性，存在选择偏差。
CHOG 测试样本少，不能据此评价长期收益。

## 验证与费用

4,641 个样本的 PyTorch 和 Python 整数原始分数一致。
九个真实行情样本的 Solidity 与本地结果一致。
Solidity 测试共十项通过，包含越界输入拒绝。
网页 BigInt 推理也通过这九个样本的差分核对。

测试网部署成功，三个资产各发送一笔决策交易。
决策事件只记录推理，不执行兑换。
合约公开固定模型哈希和数据集哈希。
合约不验证调用者的特征是否来自真实行情。
这是公开数据准备加链上模型计算的流程验证。

| 项目 | 测试网实际 gas limit | 实付测试 MON |
| --- | ---: | ---: |
| 小模型部署 | 601,288 | 0.0601288 |
| CHOG 决策 | 64,770 | 0.0064770 |
| WMON 决策 | 61,691 | 0.0061691 |
| WETH 决策 | 62,570 | 0.0062570 |
| 合计 | 790,319 | 0.0790319 |

本次有效单价为 100 MON-gwei。
总费用与钱包余额减少量一致。
直接 predict 的测试网估算为 51,276–55,339 gas。
决策交易增加事件成本，并使用 10% gas 余量。
网页免费查询用 eth_call，不花链上手续费。

比原模型便宜约 280 倍，主要因为模型参数减少。
这不是原股票模型的等价 Solidity 优化结果。

## 复现

需要 Python、CPU PyTorch 2.9.1、Node.js 和 Solidity 0.8.28。
采集需要网络。训练只消费已保存的真实数据。

```sh
python3 research/ai/monad-small/collect.py
python3 research/ai/monad-small/train.py
python3 research/ai/monad-small/audit.py
python3 research/ai/monad-small/export_contract.py
forge test --root research/ai/evm --match-contract TinyMonadPolicyTest
```

`train.py` 的 Python 环境必须安装 PyTorch。
本次使用 `/tmp/monad-model-venv/bin/python`。
全部训练参数保存在 `config.json`。

部署需要本地测试网钱包配置，脚本只接受链 10143。
脚本保存交易哈希，重跑复用已有部署与交易。
整个部署与验证设置 0.5 测试 MON 的费用上限。

```sh
node research/ai/monad-small/deploy.mjs
python3 research/ai/monad-small/build_web.py
node --test frontend/tests/monad-ai.test.mjs
node frontend/tests/monad-ai-browser.mjs
```

`deployment.json` 保存全部交易收据与九组链上核对结果。
`browser-verification.json` 保存网页到真实 RPC 的检查结果。
网页入口是 `/#ai`，也可从侧栏“交易 AI”进入。
