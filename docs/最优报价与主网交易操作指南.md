# 最优报价、20 池后端与另一台机器交易

本文对应当前实现。UI 已回退为报价页，不展示合约市场；已部署的按次收费、买断、租用、所有权合约和源代码仍保留。

## 1. 先区分三个功能

| 功能 | 网络 | 是否兑换 |
| --- | --- | --- |
| 20 pool 行情 | Monad 主网 143 | 否；监控 20 个不同币对 |
| MON → USDC 最优报价 / Buy | Monad 主网 143 | Buy 会实际兑换，当前比较 14 个已接入直接池 |
| 合约调用 / 租金 | Monad 测试网 10143 | 只重放选池，每次 0.01 测试 MON，不兑换 |

“最优”表示同金额、同方向、同一区块、已接入且可报价的候选中输出最多，不代表全链最优，也未扣 gas。WMON 按 1:1 包装 MON，池手续费已计入输出。
租金与主网兑换是独立交易。目前没有主网收费选池执行合约，测试网付费不构成主网 Buy 的强制前置条件。

## 2. 在服务机器启动后台

从项目根目录执行：

```bash
cd frontend
npm ci
npm run dev
```

保持终端运行。需要断开 SSH 后继续运行时，可先用 `tmux new -s monad` 创建会话，再执行上述命令；用 Ctrl+B 然后 D 离开会话，`tmux attach -t monad` 恢复。停止整套服务用该会话中的 Ctrl+C。

一个命令会同时启动：

| 服务 | 地址 | 用途 |
| --- | --- | --- |
| local-rpc | `127.0.0.1:8545` | 上游 RPC 路由、20 池实时采集 |
| lp-api | `0.0.0.0:8100` | 行情、报价、只读 RPC 代理 |
| Vite | `0.0.0.0:5173` | 前端，代理 `/api` 到 8100 |

页面：`http://localhost:5173/`（20 pool），`http://localhost:5173/#selection`（最优报价）。第一次运行需要 Node、Rust/Cargo 和项目本地数据库。已有环境可直接 `npm run dev`，无需反复安装。
本次排查最初 8100 没有监听，重启整套服务后已恢复。浏览器测到 20 个池的来源区块/时间都推进，价格年龄约 3–4 秒。后续以实际接口状态为准，不把本文视作永久在线承诺。

检查：

```bash
curl --noproxy '*' http://127.0.0.1:8100/api/health
curl --noproxy '*' http://127.0.0.1:8100/api/monad/prices
curl --noproxy '*' 'http://127.0.0.1:8100/api/selection/quote?amount=0.1&token_in=MON&token_out=USDC'
```

health 应有 `"ok":true`；prices 的 `prices` 数组应有 20 行，关注 `state_block`、`as_of` 和 `status`；报价应有 `sourceChainId:143`、`fresh:true`，正常覆盖 `available:14`。

如果失败：

- 连接被拒绝：检查上述终端是否退出、端口是否被占用；先启动服务。
- 8100 正常但报价 502：检查 8545 的启动日志、上游 RPC 网络和限流。
- 有数据但过期：看 `as_of` / `state_block` 是否推进；20 个池的数字恰好不变不等于没有刷新。
- 公网失败但本机正常：检查域名、隧道或反向代理；不要改成旧快照冒充实时报价。
- 本机设置了系统代理：本地请求使用 `--noproxy '*'`；公网访问按自己的网络配置代理。

## 3. 网页操作

进入“选池策略”，输入 MON 数量，查看预计 USDC、候选池、报价区块和新鲜度。
点击 **Buy USDC · 使用最优报价**，连接钱包并切换 Monad 主网。页面重新获取最优报价，核对选中池，估算并模拟交易；钱包签名后发送到对应官方路由。
默认最低到账为报价的 99.5%，即 0.5% 滑点上限；gas 另付。收到的 USDC 进入签名钱包。
当前 Buy 仅支持 MON → USDC；反向仍可报价。不存在把最优报价自动换成旧固定池的回退。

展开“合约调用 / 租金”，可用测试网钱包支付 0.01 测试 MON 并重放本轮报价。它不买 USDC，也不与主网 Buy 原子合并。

## 4. 另一台机器：最短 example

复制整个 `examples/monad-best-buy/` 文件夹，或解压 `output/monad-best-buy-example.zip`。
该目录自带路由编解码、候选池白名单和公开合约 ABI，不需要复制整个前端，也不需要后台私钥。

要求 Node.js 22.9 或更新版本：

```bash
cd monad-best-buy
npm ci
cp .env.example .env
```

`.env` 填你自己的配置，私钥只放这台签名机器：

```dotenv
MONAD_API_URL=https://lp.chayu123.me
MONAD_RPC_URL=https://rpc.monad.xyz
PRIVATE_KEY=你的本机私钥
MONAD_TESTNET_RPC_URL=https://testnet-rpc.monad.xyz
```

公网 `MONAD_API_URL` 可换成 `https://api.chayu123.me`。两者本次健康检查均成功；服务机器关闭时公网也不可用。
`MONAD_RPC_URL` 必须是允许广播的主网 RPC；网站 `/api/monad/trade-rpc` 是只读代理，不能用它发送交易。

先预览，完全不需要私钥：

```bash
node --env-file-if-exists=.env buy.mjs 0.1 --wallet 0x你的钱包地址
```

确认后实际购买：

```bash
node --env-file=.env buy.mjs 0.1 --send
```

也可以指定自己的最低到账：

```bash
node --env-file=.env buy.mjs 0.1 --send --min-usdc 0.002 --slippage-bps 50
```

每次执行 `--send` 都是一笔新的真实兑换；不要循环执行测试命令。默认 gas 上限 1,000,000，gasPrice 上限 200 gwei。余额必须覆盖 0.1 MON 本金和 gas。

流程：

1. 请求本站 `/api/selection/quote`，传金额和 MON → USDC。
2. 按原始整数比较报价，与 API 的 selected 核对；路由地址和 PoolKey 取随 example 发布的本地白名单，拒绝未知池。
3. 用你的 RPC 核对区块哈希、选中池身份及该池同区块精确输出。
4. 构造该协议的官方路由交易，设置最低到账、接收钱包、截止时间，发送前估算 gas。
5. 本机签名，计算哈希并先落盘，再广播；从回执的 USDC Transfer 日志核实实际到账。

它没有调用旧的 `/api/monad/swap/build`：旧接口是固定 V4 单池，不能代替最优接口。
预览会打印当前协议、池、路由、输出、最低到账和覆盖范围。默认 `last-buy.json` 保存发送及确认记录，允许用 `--record 文件名.json` 指定记录位置。
如果广播或确认超时，先查看打印的哈希和记录；`submitted` 状态会阻止同记录重发。不要删记录再盲目重试。

### 按协议测试（可选）

正常交易不要加这个参数。它把比较范围限制到指定协议，**不是跨全部协议的最优报价**：

```bash
node --env-file=.env buy.mjs 0.1 --protocol 'Uniswap V3' --send --record uni-v3.json
node --env-file=.env buy.mjs 0.1 --protocol 'Uniswap V2' --send --record uni-v2.json
node --env-file=.env buy.mjs 0.1 --protocol 'PancakeSwap V3' --send --record pancake-v3.json
```

### 公网未配置时

在交易机器执行 SSH 端口转发：

```bash
ssh -N -L 18100:127.0.0.1:8100 用户名@服务机器地址
```

将 `.env` 中 `MONAD_API_URL` 改为 `http://127.0.0.1:18100`。签名和广播仍使用交易机器自己的主网 RPC，私钥不会经过 SSH 转发的报价接口。

## 5. 在另一台机器测试合约租金

同一 example 目录还提供 `rent.mjs` 和 `rental.json`，后者包含实际部署的地址、创建者、收费及 ABI。

```bash
# 只预览测试网收费信息
node --env-file-if-exists=.env rent.mjs --wallet 0x你的钱包地址
# 支付 0.01 测试 MON，另付测试网 gas
node --env-file=.env rent.mjs --send
```

该脚本只允许测试网 10143。它调用 `selectAndPay(context, quotes)`，成功时费用转给创建者，返回选池结果，不执行主网兑换。
只读 eth_call 无法强制收费。已有市场合约中的 30 天租用是另一种授权机制，保留但未接在当前 UI 的按次入口。

保留的合约：

| 合约 | 网络 | 地址 |
| --- | --- | --- |
| 按次 MON 收费 | 测试网 10143 | `0x945939fdc858e731c6ea64ae08fa7c40e10ce10d` |
| Buy / Rent / Own 授权市场 | 测试网 10143 | `0xfc85b77c4788f2f5d525d4f5e601bf3eed4914bd` |
| Uniswap Universal Router | 主网 143 | `0x0d97dc33264bfc1c226207428a79b26757fb9dc3` |
| Pancake Universal Router | 主网 143 | `0x23682a588CF2601ACa977dF200938634c9F7d552` |

官方依据：[Uniswap 路由命令](https://developers.uniswap.org/docs/protocols/universal-router/concepts/commands)、[Pancake Monad 路由部署](https://developer.pancakeswap.finance/contracts/universal-router/addresses)。路由身份还通过实际链上模拟核验。
