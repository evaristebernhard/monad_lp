# 另一台电脑采集最优报价

当前后端已实现最优报价。另一台电脑可以直接调用公网 API，不需要克隆数据库、启动 Rust 后端、连接钱包或准备私钥。原来的 `buy.mjs` 是交易预览和交易执行示例，额外依赖钱包地址、Node 依赖及独立 RPC 核验；用它检查“能否采集报价”会把这些额外依赖的错误混在一起。

## 1. 先发一个最短请求

Windows PowerShell 请使用 `curl.exe`，避免旧版 PowerShell 将 `curl` 解释成其他命令：

```powershell
curl.exe --max-time 30 "https://api.chayu123.me/api/selection/quote?amount=0.1&token_in=MON&token_out=USDC"
```

Linux / macOS：

```bash
curl --max-time 30 'https://api.chayu123.me/api/selection/quote?amount=0.1&token_in=MON&token_out=USDC'
```

URL 必须整体加引号，否则 `&` 可能被终端当成控制符。备用域名是 `https://lp.chayu123.me`，其余路径和参数不变。

另一台电脑上的 `localhost` / `127.0.0.1` 指的是另一台电脑自己，不是当前服务机器。不要使用 `http://127.0.0.1:8100`，也不要仅复制网页代码中的 `/api/selection/quote` 相对地址。

## 2. 不安装依赖，直接采集数据

只需把 [`quotes.py`](../examples/monad-best-buy/quotes.py) 复制到另一台电脑的任意目录，安装 Python 3 后，在该目录执行。

Windows PowerShell：

```powershell
# 请求一次并保存完整响应
py -3 quotes.py --amount 0.1 --output monad-quotes.jsonl
# 持续采集，每轮完成后等待 2 秒，Ctrl+C 停止
py -3 quotes.py --amount 0.1 --count 0 --interval 2 --output monad-quotes.jsonl
```

Linux / macOS：

```bash
python3 quotes.py --amount 0.1 --output monad-quotes.jsonl
python3 quotes.py --amount 0.1 --count 0 --interval 2 --output monad-quotes.jsonl
```

有限次采集可用 `--count 10`。反向用 `--amount 1 --token-in USDC`；备用域名用 `--api-url https://lp.chayu123.me`。`--api-url` 只填协议和域名，不加 `/api`。没有 `--output` 时，完整 JSON 直接打印到终端；指定文件时追加写入 JSONL，并在终端显示每轮摘要。

每行完整记录保留后端原始字段，同时增加 `clientReceivedAtMs`、`clientAgeMs`、`clientFresh`。失败只输出错误，不用旧报价替代；`fresh=false` 的真实返回仍会保存，使用时需按新鲜度过滤。每轮请求串行执行，不会堆积并发请求。报价年龄计算依赖客户端时钟，请保持电脑时间同步。

## 3. 接入自己的程序时读取哪些字段

| 字段 | 用法 |
| --- | --- |
| `selected` | 最优池、协议和输出数量 |
| `scenarios[0].quotes` | 全部候选池的逐池报价 |
| `available` / `candidateCount` | 本轮有效报价数 / 已接入候选数 |
| `sourceChainId` | 应为 Monad 主网 `143` |
| `sourceBlock` / `sourceBlockHash` | 本轮共同来源区块 |
| `sourceTimestamp` | 来源区块 Unix 秒时间戳 |
| `fresh` / `ageMs` | 后端返回时的报价新鲜度；接收后需计入网络延迟 |

没有必需的顶层 `success`、`data` 或 `coverage` 字段，不要因这些字段缺失误判失败。对输出大小的比较使用 `amountOutRaw` 的整数值，不能按字符串字典序或浮点数比较。`amountOut` 是用于显示的十进制字符串。

当前范围是已接入的 14 个 MON/WMON–USDC 直接池，比较同输入金额在同一区块的输出，计入池手续费，不扣 gas；不代表全链所有池的最优路线，也不做跨池拆单。

POST 也支持，但 `amount` 必须传 JSON 字符串。例如 `{"amount":"0.1","token_in":"MON","token_out":"USDC"}`，不要传数值 `0.1`。完整接口与 SSE 订阅见 [报价 API](quote-api.md)。SSE 是 `text/event-stream`，不能对整个流直接调用 `response.json()`。

## 4. 仍失败时怎么定位

| 表现 | 首先检查 |
| --- | --- |
| 连不上 `127.0.0.1:8100` | 是否把服务器本机地址复制到了另一台电脑；改用公网域名 |
| 404 或 HTML 页面 | 路径应为 `/api/selection/quote`；域名后不要重复拼接 `/api` |
| 400 / 422 | `amount` 的字符串格式、正数、精度和 token 参数；仅支持 MON ↔ USDC |
| 502 / 504 | 保留响应正文；检查服务器应用、隧道和上游 RPC。HTTP 错误状态码本身不足以判断哪一层失败 |
| TLS / DNS / 连接超时 | 检查另一台电脑的网络、代理、防火墙与时间；不要把公网域名加入只允许本机连接的代理排除列表 |
| 返回 JSON 但程序说没有结果 | 直接读取 `selected` 和 `scenarios[0].quotes`，检查是否误读了不存在的 `data` / `success` |
| `buy.mjs` 提示缺钱包、RPC 连接失败 | 这是交易预览额外依赖；单纯采集用 `quotes.py` |
| 找不到 `.env.example` | 该文件未随本次仓库上传；采集脚本根本不需要 `.env` |

Python 标准库会读取环境或系统代理设置。curl 能访问、其他程序不能访问时，核对两者是否实际使用了相同的代理，不要假定所有语言运行时都会自动读取相同配置。

如果要进一步定位，请保留：使用的完整 URL、请求代码或命令、HTTP 状态码、响应正文或完整异常、运行时间和操作系统。不要提供私钥或代理密码。
