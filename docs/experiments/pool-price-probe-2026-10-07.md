# Pool 价格取数小范围实测（2026-10-07）

这是一轮独立探测，不是全量采集器的实现。没有修改生产采集代码、RPC 配置或价格数据库，没有使用付费凭据、oracle、TWAP 或缺失价格填充。

用户不要求整点。因此采用七天窗口内近似等间隔采样，记录实际采样块 timestamp。初始价格加 168 个后续价格，得到 168 个收益率区间；不是把 168 个点误当成 168 个相邻区间。

[完整数据与失败记录](pool-price-probe-2026-10-07.json)包含链头、池地址、token 顺序、decimals、169 个有效价格的来源以及单次探测成本。记录的总耗时只对应各自最终一次运行，不包含此前寻找端点、排查批次上限和限流的全部时间；不是统计性能基准或账单。

这是三个样本，不代表其余协议、分叉版本、活跃度或链已验证。

## Arbitrum：可复现的完整七天结果

池：0x80a9ae39310abf666a87c743d6ebbd0e8c42158e。
token0=WETH（18 decimals），token1=GMX（18 decimals）。价格定义是 GMX per WETH，由交易后的 sqrtPriceX96 计算，不是成交金额比或美元 oracle 价。

UTC 窗口：2026-09-30T13:09:13+00:00 至 2026-10-07T13:09:13+00:00，实际跨度 604800 秒。
实际采样间隔 3340–3910 秒，约 55.7–65.2 分钟。
名义小时目标与实际采样时刻最大偏差 2422 秒。没有要求精确整点；收益率计算使用实际采样间隔，而不是目标时刻。

- 七天窗口内 264 条 Swap，一次日志请求 0.57 秒、233245 bytes。
- 窗口前一段有 157 条 Swap，用最后一条建立初始状态。这是有来源的基线，不是用今天的价格倒填历史。
- 将七天区间分为两段查询，得到的事件身份/顺序与整段请求一致。这是覆盖自检，不是独立第二数据源的证明。
- 窗口起点历史 slot0 与事件基线一致，固定链头的 slot0 与事件重放终点一致。
- 所见 blockTimestamp 字段都是 0x0，不能使用。最终按共享采样块号选择此前最后一次 Swap；补查采样块的真实时间，而不是为每条 Swap 都请求块头。
- 9 个事件块时间/hash 抽样核对；起点/终点块 hash 复查一致。使用普通 latest 已出块快照，不宣称 finalized 或永久无重组。
- 169 个采样状态中，部分 source_event_timestamp 是 null，表示没有补查该事件自己的时刻；采样块时间是已获取的真实时间，价格源有 block/hash/tx/log index。null 没有当作 0 时间或缺失价格。
- 169 点对应 66 个不同来源事件。其余重复状态是完整事件路径支持的未变价格，不是对失败请求进行填补。

按实际间隔计算，等效小时波动率估计 0.4911%；七天尺度估计 6.3656%。后者采用扩散模型的时间缩放，不是年化波动率、收益率或直接交易建议。价格序列和结果已独立复算。

## 端点能力的实测限制

- Base 原公共端点：batch 最多 10 个调用；旧 slot0 单次可读，但按批次、甚至降低到单调用节奏的实验仍出现限流，不能认定稳定支持全量 archive 读取。
- Base 临时 DRPC 公开端点：旧 slot0 和元数据确实返回；普通 HTTP 客户端配置曾收到 403，已用单次请求验证的客户端配置重试。免费批次最多 3 个请求（错误明确给出）；按 3 个分批仍在整周取数中返回 HTTP 429。没有升级套餐。
- BSC PublicNode：近期 Sync 价格与同块 getReserves 一致，旧日志/状态返回要求个人 token 的错误。个人 token 不自动意味着需要付费，但本轮没有注册账号或使用未核实计费的凭据。
- PublicNode 在 Base/Arbitrum 可提供七天前的 block header，不能因旧 eth_call 失败就把它视作对所有历史数据都不可用。
- Arbitrum 公共端点此前另一个活跃池的历史 view 报 missing trie node，本样本起点却可读。应验证方法/时间范围与稳定性，不能从一次成功或失败推断整个端点的所有历史状态能力。
- 额外公开地址尝试也出现 HTTP 403/525，仅记录为本环境本次请求失败，不断言一定是收费、裁剪或链协议问题。

## 复现

在仓库根目录、现有本地 RPC 服务监听 127.0.0.1:8545 时运行：

```bash
python3 -B rpc/tools/test_price_history_probe.py
python3 -B rpc/tools/price-history-probe.py arbitrum
python3 -B rpc/tools/price-history-probe.py base
python3 -B rpc/tools/price-history-probe.py base --provider drpc-public
python3 -B rpc/tools/price-history-probe.py bsc
```

脚本有固定请求/响应大小预算、固定免费端点和请求节奏，没有无界重试。Base 的 DRPC 分支使用临时公开地址，不写回 RPC catalog。九项离线测试通过，覆盖价格方向、储备/sqrt 解码、无效数据拒绝、重复时间戳定位、错误响应 ID、日志 topic 和 URL 脱敏。

Base 对照分支只取 8 个分布在窗口中的块做 slot0/liquidity/fee 校验，不是 169 点全字段性能基准。当前全周请求尚未通过，所以不报告“快了三倍”。

## 目前可以支持的决定

常见 V3 池的事件路线已经有一个完整七天实例。链级采样映射、池级价格路径、元数据和核验应分开，端点能力还要按方法拆分。共享采样块不要求精确整点，也不要求知道每个价格事件的精确时刻。

尚不能支持的决定：全 108 组合已经有 cheap provider、所有池都适合事件、现有 Base/BSC 免费配置能稳定回填全周、或生产波动率系统已修好。本轮仍停留在独立实验。
